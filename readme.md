# A/B Testing: E-Commerce Conversion Analysis

## Overview
Analyzed an A/B experiment to determine whether a new webpage improves customer conversion rates compared to the existing version.

## Methods
- Python (Pandas, NumPy, Statsmodels)
- Hypothesis Testing
- Logistic Regression

## Key Findings
- **Treatment conversion rate:** 15.53%
- **Control conversion rate:** 10.53%
- **Improvement:** +5.01 percentage points
- Webpage type remained statistically significant (p < 0.001) after accounting for country.

## Conclusion
The results support considering the new webpage for implementation, subject to business costs and further validation.
